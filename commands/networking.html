Red y Conectividad

← Indice
Comando Descripcion Ejemplo
ip a Muestra interfaces y direcciones de red. ip addr show
ifconfig Muestra/configura interfaces de red (deprecated). ifconfig eth0
ping Prueba conectividad con otro host. ping -c 4 8.8.8.8
traceroute Muestra la ruta de paquetes a un host. traceroute google.com
ss Lista conexiones y puertos abiertos. ss -tuln
netstat Lista conexiones de red (deprecated, usar ss). netstat -tuln
curl Realiza peticiones HTTP/HTTPS. curl -O https://example.com/file.tar.gz
wget Descarga archivos desde la web. wget https://example.com/file.zip
ssh Conexion segura a un host remoto. ssh usuario@servidor.com
scp Copia archivos entre hosts via SSH. scp archivo user@host:/ruta
nslookup Consulta DNS. nslookup google.com
dig Consulta DNS detallada. dig google.com A
host Resuelve nombres de dominio. host google.com
nmap Escaneo de puertos de red. nmap -sV 192.168.1.1
