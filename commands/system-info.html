Informacion del Sistema

← Indice
Comando Descripcion Ejemplo
uname Muestra informacion del kernel. uname -a
hostname Muestra o establece el nombre del host. hostname
uptime Muestra cuanto tiempo lleva encendido el sistema. uptime
df Muestra el uso de espacio en disco. df -h
du Muestra el tamano de directorios y archivos. du -sh /home
free Muestra el uso de memoria RAM y swap. free -h
lscpu Muestra informacion de la CPU. lscpu
lsblk Lista dispositivos de bloque (discos, particiones). lsblk
lsusb Lista dispositivos USB conectados. lsusb
lspci Lista dispositivos PCI. lspci
top Muestra procesos y uso de recursos en tiempo real. top
vmstat Estadisticas de memoria, procesos y CPU. vmstat 1 5
iostat Estadisticas de entrada/salida de discos. iostat -x 1
dmesg Muestra mensajes del kernel (buffer de anillo). dmesg | tail
