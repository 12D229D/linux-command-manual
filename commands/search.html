Busqueda y Filtrado

← Indice
Comando Descripcion Ejemplo
grep Busca patrones de texto en archivos. grep -r "error" /var/log/
find Busca archivos por nombre, tipo, fecha, etc. find / -name "*.conf" -type f
locate Busca archivos rapidamente usando una base de datos. locate archivo.txt
which Muestra la ruta completa de un ejecutable. which python3
whereis Busca binarios, fuentes y paginas man. whereis bash
awk Procesamiento de texto por columnas y patrones. awk '{print $1}' archivo.txt
sed Editor de flujo para transformar texto. sed 's/viejo/nuevo/g' archivo.txt
sort Ordena lineas de texto. sort -n numeros.txt
uniq Elimina lineas duplicadas (debe estar ordenado). sort archivo.txt | uniq
wc Cuenta lineas, palabras y caracteres. wc -l archivo.txt
cut Extrae columnas de texto por delimitador. cut -d',' -f2 datos.csv
tr Reemplaza o elimina caracteres. echo "Hola" | tr 'A-Z' 'a-z'
tee Lee de stdin y escribe en stdout y archivos. ls | tee salida.txt
