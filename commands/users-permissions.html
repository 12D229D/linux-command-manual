Usuarios y Permisos

← Indice
Comando Descripcion Ejemplo
useradd Crea un nuevo usuario. useradd -m -s /bin/bash juan
usermod Modifica un usuario existente. usermod -aG docker juan
userdel Elimina un usuario. userdel -r juan
passwd Cambia la contrasena de un usuario. passwd juan
groupadd Crea un nuevo grupo. groupadd developers
groupdel Elimina un grupo. groupdel developers
groups Muestra los grupos de un usuario. groups juan
chown Cambia propietario y grupo de un archivo. chown juan:dev archivo.txt
chmod Cambia permisos de archivos. chmod 755 script.sh
sudo Ejecuta un comando como superusuario. sudo apt update
su Cambia a otro usuario (root por defecto). su - root
id Muestra UID, GID y grupos del usuario. id juan
whoami Muestra el nombre del usuario actual. whoami
visudo Edita el archivo sudoers de forma segura. sudo visudo
