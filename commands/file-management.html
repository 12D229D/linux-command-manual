Gestion de Archivos

← Indice
Comando Descripcion Ejemplo
ls Lista archivos y directorios. ls -la
cd Cambia de directorio. cd /var/log
pwd Muestra el directorio actual. pwd
cp Copia archivos o directorios. cp -r src/ backup/
mv Mueve o renombra archivos/directorios. mv viejo.txt nuevo.txt
rm Elimina archivos o directorios. rm -rf carpeta
mkdir Crea un directorio. mkdir -p a/b/c
rmdir Elimina un directorio vacio. rmdir vacia
touch Crea un archivo vacio o actualiza su fecha. touch nuevo.txt
cat Muestra el contenido de un archivo. cat archivo.txt
head Muestra las primeras lineas de un archivo. head -n 20 archivo.txt
tail Muestra las ultimas lineas de un archivo. tail -f /var/log/syslog
chmod Cambia permisos de archivo. chmod 755 script.sh
chown Cambia el propietario de un archivo. chown usuario:grupo archivo
ln Crea enlaces (simbolicos o fisicos). ln -s destino enlace
